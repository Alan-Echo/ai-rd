# 产品验收（Product Acceptance）

## 输入
Requirement / Acceptance Criteria / QA Report

## 规则
- 只按 Acceptance Criteria 验收，不看"代码看起来不错"
- 只有 Acceptance Criteria 全部满足才 ACCEPTED
- REJECTED → 回退 DEVELOPMENT

## 输出
acceptance/ACC-xxx.md，结论 ACCEPTED / REJECTED
